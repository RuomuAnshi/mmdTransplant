# MMD 自动换头 · MMD Transplant

Blender 插件：从头部来源 PMX 提取头部、头发及附属骨骼，替换身体来源 PMX 的旧头；保留身体运动骨架，合并表情与物理数据。中文界面，MIT 许可，作者 RuomuAnshi。

v0.3.3 新增“修复颈部连接”，可为可信的颈部裂缝补面、重新桥接破损连接带，保留权重与表情；修复生成预览时刚体、关节退出 Blender 物理世界的问题，并提供已有模型的物理连接修复按钮。**2. 一键生成换头模型**仍为主操作：自动分析、匹配比例、连接颈部、标记皮肤类型并过渡肤色。自动模式忽略旧的手动微调，手动控制默认折叠。

## 安装

1. 安装并启用 [MMD Tools](https://extensions.blender.org/add-ons/mmd-tools/)。
2. 从 [Releases](https://github.com/RuomuAnshi/mmdTransplant/releases) 下载安装包，或运行 `python3 scripts/package_addon.py` 自行打包。
3. 在 Blender 的“从磁盘安装 / Install from Disk”中选择 `dist/mmd_transplant-0.3.3.zip`，启用 **MMD 自动换头**。
4. 传统插件安装流程可使用 `dist/mmd_transplant-0.3.3-legacy.zip`。两种形式只需安装一种，更新时替换旧版本。
5. 在 3D 视图按 **N**，打开 **MMD 换头** 页签。

实测 Blender 5.2.1 LTS；声明最低版本 4.2，其他版本尚未实测。输入支持 PMX 2.0，暂不支持 PMD、PMX 2.1、VRM 或从任意已有场景对象换头。

## 使用

1. **A · 取头的模型**：选择头部来源 PMX。
2. **B · 保留身体的模型**：选择身体来源 PMX。
3. 点击 **2. 一键生成换头模型**，无需先点击分析。结果位于独立的 **MMD 换头预览** 集合中，默认选中可编辑的角色网格。
4. 查看结果提示并检查外观和姿势。颈部连接、肤色或定位无法可靠完成时，会明确标注 **需检查**。
5. 需要文件时展开 **导出文件**，选择输出文件夹，点击 **3. 导出 PMX + 贴图**。每次创建独立子目录，包含生成的 PMX、贴图和报告。

自动模式统一启用比例匹配、颈部连接、皮肤类型、完整强度肤色过渡和头部物理，使用标准 0.08 导入比例。旧的比例微调、位置偏移、骨骼名称和材质覆盖不参与自动生成。疑难模型可展开 **手动调整与分析**并勾选 **使用手动参数**，再运行可选的 **1. 分析头部范围**并修改参数。`是头部`让 A 包含整份材质、让 B 移除整份材质；`非头部`让 A 忽略整份材质、让 B 保留整份材质。

生成预览会安全退出当前编辑/姿态模式；生成失败时尽量恢复原选择与模式。原有场景对象保持原可见性，不自动开启局部视图。已处于局部视图时，加入新结果而不隔离其他现有对象。

重新生成会替换旧预览，包括其中的手动编辑。已有手动编辑时，**贴合当前模型颈部**只修改等点数颈圈附近的皮肤，支持撤销。不同点数的桥接需要重新生成预览，请先保存手动修改。已有完整连接面的模型重复操作不会再增加连接面。

**导出 PMX + 贴图**会根据原始输入和插件设置重新生成，不包含预览中的手动编辑。要保留手动编辑，请保存 `.blend` 并使用 mmd_tools 的标准 PMX 导出。

位置微调使用 PMX 坐标：X 左右、Y 上下、Z 前后。默认 Blender 导入比例为 0.08。自动头部比例优先测量绑定左右眼骨骼的实际几何中心距离，检查有效点数、左右对称性和眼部范围，再乘以比例微调值。几何不足时回退眼骨距；已知几何与骨骼明显冲突或定位数据缺失时保持比例 1 并提示手动检查。头骨骼名称留空时识别 `頭 / head / 头 / 頭部`；额外头发根骨骼可用英文逗号分隔指定。

## 颈部连接

- 按材质分析开放边界，几何合并 UV 拆分产生的同位置点；结合头关节与眼距定位可信的闭合颈圈。
- 相同点数：统一绕向、寻找循环对应，局部调整头侧皮肤，平滑衰减到周围区域，同时混合边界权重和顶点表情偏移。
- 不同点数：生成连续三角面带，保留原有头身坐标；连接面使用身体皮肤贴图，边界复制源顶点的权重、SDEF 与顶点表情。
- 自动模式初次连接失败时，仅对识别可信、水平中心接近且校正量不超过眼距 20% 的颈圈尝试一次上移。整体重新生成头部网格、子骨骼和物理数据，连接验证通过后才采用；大幅重叠与不可信边界仍保留检查提示。
- 权重切分导致颈部皮肤残缺：要求紧凑的颈部几何、颈/头控制权重及与头部皮肤共享的连接点。恢复完整颈部材质；重叠时只在远离下颌连接和身体其他部位的范围内修剪两侧皮肤，插值新边界的权重、UV 与表情后桥接。与首骨骼重合的辅助颈控制映射到身体颈骨骼。
- 连接面使用独立 UV 顶点，不会焊接整套网格；材料名称含 `skin`、英文名为 `neck_skin_bridge`，避免名称识别器将其判为布料。预览中写入 SKIN 标识；已转换的 ZeldaDaylight 材质使用其现有设置更新皮肤类型。
- **颈部肤色过渡**只处理新增连接带：从两端原始基础贴图按 UV 采样，排除透明和离群颜色，在线性 RGB 中生成平滑渐变，并考虑材质 diffuse 颜色。强度可调；关闭或设为 0 保留身体基础贴图。生成独立 PNG 并随 PMX 一起导出，原脸部、身体贴图与 UV 不修改。连接带上的源 UV 表情不应用到新图，原模型 UV 表情与位置表情保留。
- 新生成的连接带使用足以表达两端肤色的材质颜色基准，避免头部材质更亮时发生超范围跳过；同步换算连接带的环境色和加算颜色表情，原始材质不修改。
- **修复颈部连接**处理几何裂缝：优先操作当前选中的绑定网格，否则操作预览主网格。识别带头身来源标记的闭合颈圈，可桥接不同点数或相同点数的分离边界、替换破损连接带；复制边界权重和形态键，保留原始 UV 与其他几何修改。新连接材质自动标记为皮肤，并尝试肤色过渡。重复点击不重复补面，支持撤销；仍需通过 mmd_tools 导出保存。边界标记丢失、严重交叉、距离过大或已绑定 SDEF 缓存时提示人工检查，不执行任意全模型补洞。
- **修复当前颈部材质**保留当前几何、权重和表情，修正旧连接带类型并可生成肤色过渡，支持撤销。已有连接带受 UV 表情或自定义 UV 映射控制时只标记皮肤类型，提示重新生成；不覆盖手动节点。该按钮的修改仍需通过 mmd_tools 标准导出保存。
- 未新增连接带、颜色采样不足/过暗/多色、透明边界或不支持的自定义节点会跳过肤色匹配并提示。它匹配基础贴图色，不拟合动态球贴图、灯光或阴影；两端纹理差异较大时仍需人工检查。衣领轮廓与头发碰撞仍需检查。
- 未识别到完整颈部皮肤，或无法确认安全修剪范围时，颈圈破损、交叉、反向、距离过远或缺少定位骨骼会跳过并提示；不对任意输入保证无缝。

生成 PMX 时，相同点数贴合区域和修剪新增顶点的 SDEF 转为 BDEF，其他区域保留原权重类型。当前网格若含已绑定的 SDEF 辅助形态键，局部贴合按钮会提示使用重新生成流程。

当前模型按钮依赖插件预览集合、`头_` / `身_` 材质前缀和可识别的日文头/眼骨骼。删除或改名后可能需要手动处理。

## 在 mmd_tools 中继续编辑

`model` 是根空对象，`model_arm` 是骨架，`model_mesh` 是角色网格。

- 摆姿势：选择骨架，进入姿态模式。
- 修改骨架结构：选择骨架，进入编辑模式。
- 编辑顶点和面，或转换材质：选择网格。
- 看不见骨骼或编辑辅助线：检查 3D 视图的叠加显示与骨骼开关。
- 使用物理：回到模拟起始帧，在 MMD Tools 中构建物理，再连续播放或烘焙。生成预览时保留刚体世界的刚体/关节集合成员关系；仅保留 PMX 中的刚体数据并不足以让 Blender 模拟它们。
- 旧预览头发不模拟：点击 **修复已有模型物理连接**，再从起始帧重新构建/播放。修复仅补回当前预览的集合成员关系，不修改几何、动作、质量、阻尼、碰撞组或关节限制，支持撤销。存在已烘焙缓存时需清除旧缓存并重新烘焙。

## 保留机制

保留身体的颈部、头部控制及运动骨架；替换旧头部子骨骼，重映射权重、父级、追加变换、IK 与显示枠。无法保留的跨边界 IK 会报错。

保留存活顶点、骨骼与材质的表情偏移。同名同类型表情合并为一个控制，组表情引用重建，全材质偏移限制在各自来源的存活材质范围内。

保留身体物理，并可加入新头部刚体与关节。源骨架需处于常见的 MMD 正面休止姿态；不同朝向、休止姿态或衣服碰撞仍可能需要手动处理。原始输入与贴图不修改。

## 开发与验证

```sh
python3 -m unittest discover -s tests -v
python3 scripts/package_addon.py
```

公开测试仅使用程序构造的合成数据，覆盖索引重映射、SDEF 缩放、错误输入、材质范围、颈圈匹配、不同点数桥接和重复操作。

发布前更新插件版本与 `.github/release-notes.md`，再推送对应的 `v` 版本标签。GitHub Actions 会检查公开源码、运行合成测试，并将两种安装包发布到 Release；标签必须与插件清单中的版本一致。

## 发布范围

仓库仅发布通用插件源码、合成测试与通用文档。模型、贴图、动作、场景、来源路径、材质清单、截图及实际输入的验证数据均保留在本地。`output/`、`dist/`、`scripts/local/` 及常见资产格式已加入忽略规则。

mmd_tools 是运行依赖，不复制到插件安装包中。
